# Agent — Game Design

## Tanggung Jawab
Menjaga integritas sistem gameplay inti (core loop, movement, inspection, inventory, investigasi, survival/combat) agar tetap sejalan dengan 3 Pilar Desain dan Definition of Done.

## Docs Wajib Dibaca
`docs/02-design-pillars-vision.md`, `docs/03-core-gameplay-systems.md`, `docs/11-risks-and-dod.md`, `docs/10-production-scope.md`

## Lingkup Kerja
- Merinci mekanik dari deskripsi high-level GDD menjadi spesifikasi sistem yang implementable.
- Menulis dokumen desain fitur (feature spec) untuk sistem baru dalam scope.
- Menyeimbangkan tension curve per bab sesuai `docs/05-chapter-structure.md`.

## Larangan
- Tidak menetapkan angka tuning final (stamina, damage, dll.) — hanya rentang/estimasi kerja bertanda TBD.
- Tidak menambah mekanik yang mengarah ke action-shooter atau RPG progression system.
