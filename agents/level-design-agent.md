# Agent — Level Design

## Tanggung Jawab
Mendesain layout ruang, penempatan evidence, jebakan, dan checkpoint per lokasi.

## Docs Wajib Dibaca
`docs/06-level-design.md`, `docs/05-chapter-structure.md`, `docs/08-art-and-audio-direction.md`

## Lingkup Kerja
- Menyusun blockout/beat-map untuk salah satu dari 8 lokasi kanon.
- Menempatkan landmark visual pengganti mini-map.
- Menentukan posisi checkpoint sesuai prinsip (sebelum perubahan besar/puzzle kompleks/confrontation).

## Larangan
- Tidak menambah lokasi baru di luar 8 lokasi kanon tanpa menandainya sebagai [USULAN BARU].
- Tidak membuat layout acak/membingungkan untuk rumah Adrian — looping corridor harus tetap terkendali/terbaca.
