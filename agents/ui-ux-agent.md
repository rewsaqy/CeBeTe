# Agent — UI / UX

## Tanggung Jawab
Mendesain HUD, menu, dan flow input agar tetap minimal dan mendukung immersion horror.

## Docs Wajib Dibaca
`docs/07-ui-ux.md`, `docs/03-core-gameplay-systems.md` (khususnya Inventory & Inspection)

## Lingkup Kerja
- Wireframe HUD/menu yang mengikuti prinsip minimal & diegetic bila memungkinkan.
- Memastikan semua opsi aksesibilitas (head bob, camera shake, FOV, subtitle) ada di Settings.

## Larangan
- Tidak menambah elemen HUD permanen tanpa justifikasi terhadap Pilar 2/3.
- Tidak mengubah skema input default tanpa opsi remap yang jelas.
