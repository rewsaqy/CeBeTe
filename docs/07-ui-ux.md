# 07 — UI / UX

## HUD
- Health: minimal, bisa diegetic (kondisi visual/body feedback)
- Stamina: muncul hanya saat dipakai/rendah
- Interaction prompt: kontekstual
- Hand slots: tampil singkat saat item diganti
- Crosshair/focus dot kecil, opsional dimatikan
- Subtitles aktif default (voice direction awal = text-only)

## Menu
- Evidence Log / Case File
- Inventory: Left Hand, Right Hand, 4 Pocket Slots
- Quest Log / Current Objective
- Settings: graphics, audio, keybind, subtitles, FOV, sensitivity, head bob, camera shake, accessibility
- Pause Menu: Resume, Load Checkpoint, Settings, Main Menu

## Input Default (PC)
| Input | Aksi |
|---|---|
| WASD | Movement |
| Mouse | Look & rotate item |
| Left Click / E | Interact / examine |
| Mouse Wheel | Zoom inspection / quick selection kontekstual |
| Shift | Sprint |
| Ctrl / C | Crouch |
| Space | Limited jump |
| Tab | Inventory / case file |
| R / kontekstual | Reload / item-specific action |

## Batasan untuk Agent
- HUD wajib minimal by design — jangan menambah elemen permanen di layar tanpa alasan kuat terhadap Pilar 2 & 3.
- Semua opsi aksesibilitas (head bob, camera shake, FOV, subtitle) wajib togglable — ini bukan nice-to-have.
- Skema input default di atas adalah baseline; remap disediakan lewat Settings, bukan mengganti default ini secara diam-diam.
